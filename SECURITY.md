# Security policy

Report a vulnerability through the repository's GitHub Security advisory
workflow. If private reporting is unavailable, open a minimal issue asking
for a secure channel without posting exploit details or credentials.

XCP treats source trees, programs, manifests and target observations as
untrusted. Admission must precede execution. The Python XVM reference is a
semantic oracle, not a hardened process sandbox. Its public snapshot test key
cannot authenticate an Xbox worker snapshot. Do not run unknown code outside
an appropriate sandbox or grant an adapter access to secrets.
